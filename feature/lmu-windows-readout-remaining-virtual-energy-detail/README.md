# lmu-windows-readout-remaining-virtual-energy-detail

LMU のバーチャルエナジー残量を読み上げる機能の詳細設定画面。バーチャルエナジー残量が設定した閾値（10〜90%、デフォルト50%）以下になったタイミングで警告を読み上げる。「残量警告」チップをタップすると警告音声を試聴でき、閾値スライダーの設定値は DataStore に永続化される。
