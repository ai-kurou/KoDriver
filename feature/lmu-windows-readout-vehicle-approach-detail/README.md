# lmu-windows-readout-vehicle-approach-detail

接近開始時は左右それぞれの自由文言を入力・保存し、個別に試聴できる（上限30文字、空白は読み上げない）。TTSを利用できない端末では案内を表示し入力・試聴を無効にする。試聴は音量が正の場合にRootキーの開始音を鳴らしてからOS標準TTSで読み上げる。継続時は既存の収録WAV選択・試聴を維持する。
