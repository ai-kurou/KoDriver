# ace-windows-narrator

ACE (Assetto Corsa EVO) Windows版のWAV音声再生とアナウンス制御。`feature:lmu-windows-narrator` /
`feature:gt7-ps5-narrator` に相当する ACE 版。

現時点ではモジュールの雛形のみで、アナウンスロジック（ViewModel・SoundPlayer・WAVリソース）は
未実装。別 PR で実装する。
