# start-implementation

ユーザーが実装を依頼したときに、このSkillに従って作業する。引数は「実装内容」「ベースブランチ」「CodeRabbitへのレビュー依頼有無（`true` / `false`）」の順。ベースブランチは省略時 `main`、CodeRabbitへの依頼は `true` のときだけ行う。第三引数が `true` / `false` 以外なら作業を始めず確認する。

Codexでは会話で `$start-implementation <実装内容> [ベースブランチ] [true|false]` と指定する。このSkillを使う指示を受けた場合も同じ手順で動く。

## 実装

1. 実装内容が空なら、内容を確認して終了する。
2. リポジトリルートで現在のブランチと `git status --porcelain` を確認する。未コミット変更があれば触らず、報告して終了する。
3. ベースブランチを確認する。`git fetch origin <base>` を行い、リモート追従ブランチなら最新化してよい。ローカルにしかないブランチはそのまま使う。存在しないブランチは作成せず終了する。
4. 実装内容から prefix（`feature/`、`fix/`、`chore/` 等）付きの英語 kebab-case ブランチ名を決める。`.claude/worktrees/<prefixを除いたブランチ名>` に `git worktree add` で作業用ワークツリーを作る。既存の同名ブランチやワークツリーがあれば上書き・削除せず終了する。
5. 新しいワークツリーで `AGENTS.md` と `CLAUDE.md` および適用される資料を読み、実装前チェックリストに従って類似実装・対象モジュール・依存方向・必要なテストを確認する。
6. プロジェクト指示に従って実装し、実装コードと同時にユニットテストを追加・更新する。`moduleGraphAssert` ブロックは変更しない。モジュール図やスクリーンショット画像をステージングしない。
7. 完了前チェックリストに従う。変更範囲に応じたスクリーンショットテストを実行し、必ず `./gradlew preSubmitChecks` を実行して失敗を解消する。実行できない場合は理由を明記する。
8. 関連する既存 GitHub Issue を `gh issue list --search` などで確認し、今回の実装で解決したIssueがあれば関連PR番号とともにクローズする。

## コミットとPR

9. Git操作ルールに従い、feature ブランチでコミット、プッシュ、PR作成まで進める。コミットメッセージは日本語。PRタイトル・説明も日本語とし、署名やセッションURLを含めない。`main` への直接コミット・プッシュは事前にユーザーへ確認する。
10. `true` が指定されているときだけ、PR作成後にCodeRabbitへ手動レビューを依頼する。`.coderabbit.yaml` の設定を確認し、PRトップレベルコメントから CodeRabbit の `Trigger review` チェックボックス行を探す。動的な `checkboxId` を含め、該当行だけを未チェックからチェック済みにして更新する。ほかの本文は変えない。

## CIと指摘の報告

11. `gh pr checks <番号>` で確認し、pending があれば適切な間隔で再確認する。この実行環境にスケジュール実行・再開機能があればCI確認を予約して再開する。利用できない場合は無限に待たず、現状をユーザーへ伝えて後で再開できるようにする。
12. 全チェック完了後、PR概要とstatus checks、トップレベルコメント、インラインレビューコメント、レビュー本体を取得して、各 `body` 全文を読む。指摘の内容・場所・妥当性・修正要否をプロジェクト方針と照らして整理し、ユーザーに報告する。
13. 指摘へのコード修正・返信投稿は、このSkillの範囲では行わない。ユーザーから別途依頼があった場合に対応する。
14. ChatGPT Remote Control 固有のPushNotificationツールはCodexから利用できないため実行しない。Codexの会話上で通常の完了報告を行う。

## 安全上の制約

- 新規作成したワークツリー・ブランチだけを扱い、既存のものを削除・上書きしない。他セッションのワークツリーに触れない。
- スクリーンショット画像・モジュール図をステージングしない。
- ユーザーの依頼なしにPRへコメント、マージ、修正コミットの追加をしない。
- CIの再確認待ちの間も進捗を報告し、利用できない再開機能を使えるものとして装わない。
