# 音声タブ ロードマップ

ベースブランチ `feature/base/speech-tab` で少しずつ実装する「音声タブ」（読み上げ項目と、それを読み上げさせる語句の一覧）の仕様と進捗。
`/cleanup-worktree` が、マージ済みPRのベースブランチ（`feature/base/*`）に対応するこのファイルを読み、次の実装候補を提示する。

- ファイル先頭のフロントマターに `base-branch:` を持つロードマップだけが対象になる。
- PR をマージしたら、同じ PR または直後の PR でチェックを付ける（実装済みの履歴は `git log main..<base-branch>` でも確認できる）。
- 実装しながら仕様が変わったら、このファイルを同じ PR で更新する。
- 右下の音声認識チップの仕様は [`speech-recognition.md`](speech-recognition.md) にある（こちらは完了済み）。

## 背景

音声認識でウェイクワード「コドライバー」に続けて語句を言うと、対応する項目が読み上げられる。ユーザーが「何と言うと何が読み上げられるか」を確認できる画面がないため、音声タブを追加し、読み上げ項目と語句の一覧を見せる。

## 仕様（合意済み）

今回の対象は listPane のみ。

- 他のタブと同じく、シミュレーターが選択された状態で表示する。画面内にシミュレーターの表記は出さない。
- 一覧の先頭に、呼びかけの案内を固定表示する。ユーザーに言わせるのは「コドライバー」だけで、「コドライバー → 確認音が鳴る → 語句 → 読み上げ」の流れを1行で示す。内部で反応する別の表記（「ドライバー」「このドライバー」）は案内に出さない。3ステップの下には、長い語句を優先する旨の補足文を1つ添える。
- 読み上げ項目1つを1枚のカードにする。手動読み上げタブと同じく `ElevatedCard`（`surfaceContainerLow`）を使い、カードは種類（燃料・タイヤ・ブレーキ・ラップなど）ごとの見出しでまとめる。
- カードには項目名と、その項目を読み上げさせる語句を、省略せずすべて並べる（「+N」で省略しない）。
- 読み上げのオン・オフは表示しない。
- 検索・絞り込みは入れない。
- detailPane は今回対象外。
- 設計案の見た目は、非公開の設計案 HTML で確認した（リポジトリには置かない。項目名・語句・種類の名前は表示例）。
- 項目名は既存の表記に合わせる（例: 「バーチャルエネルギー」。「ヴァーチャル」ではない）。

## 未決事項

- 語句の定義先: 解決した。各シミュレーターのドメインモジュールに手動読み上げの語句（`*ManualReadoutItemPhrases`）が既にあり、音声認識の照合と共有している。`ManualReadoutSimulatorSpec.itemPhrases` に載せて registry から引く。
- 語句の表示: 定義には「ガソリン」「燃料の残量」のような言い換えや「燃料周回」「燃料は何周」のような周回数の言い方も含まれ、項目によっては十数語になる。合意済みの仕様どおり、まずは省略せずすべて出す。表示用に絞るかは、実際の見た目を見て改めて判断する。
- 種類（グループ）の分け方と順序は、手動読み上げタブのカテゴリ（`ManualReadoutItemCategory`）の順に合わせた（UseCase で実装済み）。変えたい場合は見直す。
- シミュレーターごとに項目が違う場合は、選択中のシミュレーターの項目だけを出す（UseCase で実装済み）。
