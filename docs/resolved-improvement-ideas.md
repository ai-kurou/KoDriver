# 対応済み改善案ログ

`docs/improvement-ideas.md` から削除した項目を、1行の短いサマリとして記録するファイル。

- `improvement-ideas.md` から項目を削除する際（対応済み・不要判断のいずれの場合も）は、削除と同じ PR でこのファイルに1行追記する。
- 目的は、夜間バッチ（`nightly-todo.yml`）や実装作業が、過去に対応済み・検討済みの内容を重複して `improvement-ideas.md` に再度追記してしまうことを防ぐこと。詳細な「対象・課題・改善案」は残さず、後から見て何の話か分かる程度の一言に留める（肥大化を防ぐため）。
- 書式: `- YYYY-MM-DD 一言サマリ（関連PR #番号）`
- 古い記録を削除してよいタイミングは特に定めない。基本的に追記のみで運用する。
